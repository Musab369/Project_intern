# Budget Tracker

> A clean and responsive **Budget Tracker** built with **React.js** and **Tailwind CSS** to help users manage their income, expenses, and overall budget in a simple way.

## ✨ Features

* 💵 **Track Income** — Add and manage your income.
* 💸 **Track Expenses** — Keep a record of your spending.
* 📊 **Budget Overview** — Quickly see your financial situation.
* 🧮 **Automatic Calculations** — Income, expenses, and balance are calculated automatically.
* 🗑️ **Delete Transactions** — Easily remove unwanted transactions.
* 📱 **Responsive Design** — Works smoothly across desktop, tablet, and mobile.
* 🎨 **Modern UI** — Clean interface built with Tailwind CSS.
* ⚡ **Fast & Lightweight** — Powered by React.js.

## 🚀 Run Locally

### 1. Clone the repository

```bash
https://github.com/Musab369/Project_intern.git
```

### 2. Navigate to the project

```bash
cd Budget_Tracker
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.
